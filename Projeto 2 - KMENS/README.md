# Trabalho Prático 02: K-Means (Base Iris)

Repositório dedicado à implementação e análise do algoritmo **K-Means** (aprendizado não supervisionado) aplicado à clássica base de dados **Iris**, desenvolvido no âmbito da disciplina de Inteligência Artificial.

## 📋 Sobre o Projeto
O objetivo principal é compreender na prática como o algoritmo K-Means forma os agrupamentos (clusters), analisar a influência da variação do número de clusters ($K$), avaliar o impacto de diferentes pré-processamentos e mensurar o desempenho do modelo utilizando métricas internas e externas (comparando os clusters gerados com os rótulos reais das espécies de flores).

## 🛠️ Tecnologias e Bibliotecas Utilizadas
O projeto foi desenvolvido em **Python** utilizando as seguintes bibliotecas:
* `pandas` e `numpy` (Manipulação e estruturação de dados)
* `scikit-learn` (Implementação do K-Means, pré-processamento, PCA e métricas de avaliação)
* `matplotlib` e `seaborn` (Visualização gráfica e geração de relatórios visuais)
* `scipy` (Algoritmo Húngaro para alinhamento ótimo de clusters)
